## 设计原则

1. **节奏三幕结构**：
   - **第一幕** (0:00–1:00 / PI①–⑤)：高密度情绪过山车（钩子+共情+振奋）
   - **第二幕** (1:00–12:00 / PI⑥–⑭)：教学实操 + 稀疏 PI 确保沉浸
   - **第三幕** (12:00–结束 / PI⑮–⑯)：情感收束 + 行动号召

2. **屏幕录制原则**：
   - 录屏区域始终带粉白 `#D4A5A5` 细边框（1px）+ 圆角 `8px`
   - 章节标题卡在左上角常驻，段落切换时过渡动画（向右滑出/向左滑入）
   - 鼠标点击处加半透明粉圈 `scale: 1→1.3, opacity: 0.6→0` 指示
   - 终端输出逐行流式出现（模拟真实打字效果）

3. **比喻视觉统一**：
   - 所有比喻使用相同图标风格（线框矢量 + 纯色填充）
   - 比喻图标大小统一 `64×64px`
   - 比喻卡片格式一致：图标 + 标题（粗体）+ 单行描述

4. **入场方式区分角色**：
   - 正常内容 → 中央淡入 (`scale: 0.92→1`)
   - 比喻元素 → 侧边滑入 (`x: ±60→0`)
   - 报错/警告 → 右侧弹出 + 旋转 (`x: 400→0, rotation: ±5→0`)
   - 成功确认 → 缩放弹入 (`scale: 0→1`)
   - 大纲/列表 → 依次左滑入 staggered

5. **色彩传达情绪**：
   - 粉 (`#D4A5A5`) = 温暖/品牌/鼓励
   - 紫 (`#9B8AA5`) = 专业/产品/神秘
   - 红 (`#E74C3C`) = 警告/共情/挫折
   - 绿 (`#27AE60`) = 成功/通过
   - 奶白 (`#F5F0F0`) = 舒适/可信/教程
   - 暗 (`rgba(0,0,0,0.45)`) = 压抑/共情

6. **不给信息过载**：
   - 每个动画段落之间留 1–3s 纯缓冲
   - 录屏段落不做频繁动画干扰（PI 间距最大 274s）
   - 比喻概念首次出现时单独展示，复用时不解释

7. **Remotion 实现建议**：
   - `useCurrentFrame()` + `interpolate()` 替代 GSAP `tween`
   - `spring()` 替代 GSAP `back.out()` 弹性效果
   - `<Sequence>` 嵌套管理段落时长
   - `<View style={{...transform}}>` 替代 `x/y/scale` 属性
   - 每个段落封装为独立 `<Composition>` 便于调试
   - 录屏素材以 `<Img>` 序列帧或 `<Video>` 嵌入
   - 粒子系统用 `@remotion/particles` 或自定义 `useMemo` + `canvas`
